# Lightdive 美術素材清單（v1 測試網）

依據：《NFT 世界觀與故事 v3》第 3 節的視覺指引，以及白皮書 v1.0。目前遊戲畫面用幾何圖示代替，素材到位後替換即可。

## 共通規格

- 格式：PNG，sRGB。圖層素材用透明背景。
- 尺寸：NFT 肖像與光塔、稜鏡一律 **1024×1366**（直式，與 v3 的 v5 樣品對位一致）。
- 檔名：`{類型}_{層或部件}_{稀有度1-5}_{變體}.png`，例如 `seeker_E_3_a.png`、`spire_lv4.png`。
- 品牌核光色：萊姆綠 `#C9FF55`（v3 寫 #C6FF3D 左右，請統一成網站主色）。
- 禁止：文字、Logo、數字、星級符號；骷髏、墓碑、血跡；礦鎬、鏟子、礦燈、安全帽等挖礦造型；武器感太重的造型。
- 授權：生圖工具必須允許商用，保留每張圖的生成紀錄（工具、日期、提示詞）。

## 2. 光塔 Beacon Spire

- Lv.1–5（對應微光～曜核）各 1 張，泊位數量＝等級，正面要數得出來：**5 張**
- 特別款：空心塔、創世塔：**2 張**
- 規格與構圖見 v3 第 3.4、3.6 節（分體古石巨碑、晶核、三爪稜鏡座、沒有光柱）。

## 3. 共鳴稜鏡 Resonance Prism

- 稜鏡本體：5 稀有度：**5 張**（透明背景，底座接口統一）
- 光束：廣域、聚焦、針芒：**3 張**（獨立透明圖，疊在本體上；一律萊姆綠）
- 特別款：回聲稜鏡、核心之淚：**2 張**

## 4. Signal-Keeper（遊戲 NPC）

現有三張概念圖可以當主視覺。另外需要透明背景、同一角度的 NPC 立繪，用在新手引導和公告：

| 姿勢 | 用途 |
|---|---|
| 站立待機 | 預設 |
| 手指終端（SIGNAL） | 公布當日座標與異相 |
| 軌道球亮起 | 潛光成功、罕見光焰 |
| 低頭、軌道球變暗 | 光橋中斷 |
| 張開手、胸口核心強光 | 核光回響、賽季公告 |

**5 張**，1024×1536，透明背景。每次生圖都貼同一段角色設定提示詞，避免外觀跑掉。

## 總量

最低約 **97 張**（探索者 66＋光塔 7＋稜鏡 10＋NPC 5＋介面 14 張，其中結果特效 5 張可以用短動畫取代）；建議版本約 120 張。

## 優先順序

1. 探索者 A／B 層、光塔 Lv.1–3、稜鏡本體與光束、星圖背景：測試網公開試玩前就需要。
2. 其餘探索者層、光塔 Lv.4–5、Signal-Keeper 立繪。
3. 特別款、星紋背景、結果特效、分享圖。
