# 潛光遠征：遊戲深度通盤思考（v1，2026-10-16）

這份是提案，還沒有實作。依據是 10-16 我用四種玩家（新手、衝收益的老手、市集交易者、回鍋玩家）在本機鏈上實際玩過的結果，加上目前 v3 合約的規則。

## 一、現況診斷：哪裡太淺

| 環節 | 現在的樣子 | 問題 |
|---|---|---|
| 每天的節奏 | 3 張出發令，「一次派遣」按一下就全部用完 | 每天真正需要思考的時間大約 5–10 分鐘，之後到換日都沒事可做 |
| 選目的地 | 戰力夠就能去；越深收益越高；每天換光和星象 | 有「最佳解」，觀測站的「今日航線建議」甚至直接幫玩家算好了，等於沒有選擇 |
| 航行抉擇 | 一趟一次，三選一，平均值只差 ±3% | 選項和隊伍組成無關，感覺像擲硬幣；你 10-09 也說過「選啥都沒變化」 |
| 組隊 | 戰力加總，同頻探索者多算自己戰力的 15%，全隊最多 +10% | 最佳解很明顯：把戰力最高的人塞進去就對了 |
| 長期目標 | 抽更好的卡 | 沒有累積、沒有個人紀錄、沒有「我這個玩家是誰」的身分感 |
| 玩家之間 | 市集，加上共用的分配率（人越多每點分得越少） | 只有被動的競爭，沒有看得見的互動 |

一句話：**現在的遊戲是「抽卡 → 照建議出發 → 收取」的流水線，玩家能做的有意義選擇太少。**

## 二、設計原則（沿用你之前的決定）

- 每個選擇都要有取捨，不能有唯一解。
- 深度要來自「隊伍怎麼組」和「何時、去哪」，不是更多運氣。
- 規則公開、可以在鏈上驗證。
- 不承諾收益，不另外發新幣。
- 不做卡片圖鑑、一鍵組隊和明日星象預告（你都否決過）。
- 故事文字裡不能出現機制用語。

## 三、提案

### 第一層：不改合約，現在就能做

**A. 足跡：目的地的故事碎片**
- 每個目的地第一次抵達時，解鎖一段那個地方的故事（文學性文字，延續故事卷的世界觀，不含機制用語）。
- 24 個目的地，每地 2–3 段。玩家有理由去「沒去過的地方」，而不只是去收益最高的地方。
- 這是「地點的故事」，不是卡片圖鑑，跟你否決的圖鑑是兩件事。
- 進度記在鏈上的出航紀錄，換電腦也看得到。

**B. 航海紀錄與排行榜（純榮譽）**
- 個人紀錄：最深到達的目的地、最高倍率、傳說次數、連續出航天數、到過幾個目的地。
- 公開排行榜：每日最高倍率（現在已經有）、每週光塵總量、每週最深到達。
- 沒有代幣獎勵，只有名字和稱號，所以不碰經濟。

### 第二層：v3.1 合約改版（要你同意，並重新部署測試網）

規則改動最好在正式網上線前一次做完。正式網合約部署後要再改規則，代價會大很多。

**C. 目的地擁擠度（最推薦）**
- 每個目的地每天的收益權重，會隨當天出發的趟數遞減。例如前 20 趟全額，之後每多 10 趟少 2%，最低 70%。
- **效果：**
  - 「今日最佳點」不再是唯一解。大家都去的地方會變擠，冷門路線反而划算。
  - 早出發有價值，玩家之間有了看得見的間接博弈。
  - 即時紀錄變成有用的情報，因為能看到別人都去哪裡。
- **合約：** 加一個「每天 × 每個目的地」的計數，在計算光塵分時乘上一個係數。改動小。
- **風險：** 有人多開錢包去搶前排。不過每個錢包每天只有 3 張出發令，加上要先有卡，多開的成本不低。

**D. 光紋組合（讓組隊變成拼圖）**
- 在現有的「同頻」之外，再加兩種組合：
  - **共振：** 3 位同光紋 → 收益權重 +x%。
  - **全光譜：** 隊上的光紋都不重複，且至少 4 種 → 空手機率 −y 點。
- **效果：**
  - 高泊位（高稀有度）的光塔才組得出組合，價值更高。
  - 探索者的光紋變成市集上真正有需求的特性，交易更活絡。
  - 每天的光不同，要用共振還是全光譜，就有了取捨。
- **合約：** 改 `teamPower` 和 `plan` 的計算，網站的規則程式也要同步改，再用 3,456 組比對測試確認兩邊一致。

**E. 抉擇卡跟隊伍組成掛鉤**
- 現在的三選一是通用選項。改成：事件卡依目的地星團出現，**某些選項要隊上有特定光紋或稜鏡才能選**。
  - 例如「霧中迷途」：隊上有霧光探索者，就多一個「循光前進」選項（低風險、小加成）。
- **效果：** 6 種光紋各自有派上用場的時候。抉擇時看的是「我帶了誰」，不是擲硬幣。
- **合約：** 事件由出航編號的雜湊決定（鏈上算得出來），選項是否可用依隊伍光紋判斷。中等複雜度。

**F. 合成（卡片的去處和成長）**
- 3 張同稀有度的探索者 → 合成 1 張高一階的，有機率失敗；失敗時保底返還 1 張同階的。
- **效果：**
  - 給閒置卡一個去處。經濟模擬器發現「閒置卡佔住上限」，合成可以消化它。
  - 也多了一條除了抽卡之外的成長路線。
- **風險：** 會影響各稀有度的實際分佈，和公開機率之間的關係。一定要先在經濟模擬器（`tools/lightdive-econ`）跑過才寫合約。

### 第三層：之後再做

**G. 遠征模式：** 一次用 2 張出發令，走 15 分鐘的長航線，中途 2 次抉擇，倍率上限更高。讓節奏有長短變化。

**H. 合作目標：** 每週一個「深淵目的地」，全服累積的光塵達標才開啟。開啟後所有參與者都有額外的故事或稱號。屬於社群目標。

## 四、建議的順序

1. **現在（不改合約）：** A 足跡、B 航海紀錄與排行榜。
2. **v3.1 合約包（一次改完再上測試網）：** C 擁擠度、D 光紋組合、E 抉擇卡掛鉤，F 合成要等模擬結果。每一項都先用經濟模擬器跑，再寫合約和測試。
3. **之後：** G 遠征模式、H 合作目標。

## 五、需要你決定的

1. 第一層的 A、B 要不要做？
2. v3.1 合約包要放哪幾項？
3. 擁擠度、組合加成的數字範圍（先給我方向，我用模擬器跑出建議值）。
