# 潛光遠征 玩法書 v2（草案）

狀態：草案（2026-10-07）。規則和數值以《規則書 v2》為準，這份寫的是**玩家實際怎麼玩、每個畫面做什麼、按下去會發生什麼**。
做法：先依照這份玩法書把遊戲內容做出來（預覽模式，見第 13 章），合約之後再補上鏈的部分。

---

## 1. 一句話玩法

**每天拿到 3 張出發令，挑隊伍、挑目的地、決定要穩還是要搏，把光帶回來，換成 RVYN。**

玩家的三個長期目標：
1. **變強**：抽到、換到更好的光塔、稜鏡、探索者，讓隊伍到得了更深的星團。
2. **收集**：圖鑑裡的同頻紀錄、結果紀錄、稀有度和特別款。
3. **把握每一天**：每天的光都不同，3 張出發令怎麼分配，每天都要重新判斷。

## 4. 每天的一輪

1. **打開觀測站**：看今天的公告、星團預報（哪裡的光和你的探索者同頻）、還剩幾張出發令。
2. **到潛光頁**：在星圖上挑星團 → 點開挑目的地 → 確認出發。
3. **重複最多 3 次**：可以 3 次都用同一支隊伍，也可以分給不同隊伍。
4. **約 1 小時後**：結果揭曉，右側即時日誌出現你的結果和其他人的動態。
5. **隔天**：前一天的光塵換成 RVYN，進到金庫。等越久提領，手續費越低。
6. **不定期**：抽新卡、調整隊伍、處理停泊的 NFT（續航或讓它歸航）。

## 5. 各頁面做什麼（一頁只回答一個問題）

### 5.1 觀測站：「今天有什麼事？」
- **今日的光**（主視覺）：今天的日期、12 個目的地今天各是什麼光，用六色光點排成一條，並融入今日意象。
- **Rovyn**：點一下換一句話。台詞依玩家狀態輪替（見第 9 章）。
- **公告與活動**：後台管理的公告列表，可上架、下架，有文字和連結。
- **今日次數**：出發令剩幾張（例如 2／3）、換日倒數、停泊中的 NFT 數量。
- **新手任務**：第 3 章的流程，全部完成後收起。
- **星團預報**：今天每個星團裡，哪個目的地和你的探索者最同頻；點一下直接跳到潛光頁的那個目的地。

不放：隊伍細節、資產列表、收益數字（那些在別頁）。

### 5.2 潛光：「今天要去哪裡？」（主要玩法）

**左側：主畫面，三層**
1. **星圖**：4 個星團排在深空中，越深越靠近畫面中央的核心。
   - 滑鼠移上去：星團發亮、緩慢旋轉，顯示名字、光度區間、風險等級（穩／中／險／極險）。
   - 到不了的星團顯示鎖頭和「需要光度 X」。
   - 點一下 → 鏡頭推進，展開星團。
2. **星團內**：3 個目的地 A／B／C，各自顯示今天的光。
   - 左上角「← 星圖」返回。
   - 點目的地 → 右側滑出**目的地卡**。
3. **目的地卡**：名字、故事介紹、門檻、今天的光、收益係數、補給比例、勝算表（依你選的隊伍和稜鏡即時換算）。下方是「選擇隊伍出發」。

**出發確認（最重要的畫面）**，必須一眼看懂：
- 隊伍：哪座光塔、稜鏡（光束）、哪些探索者；同頻的探索者亮起光紋。
- 光度：隊伍總光度／門檻；超出門檻多少，空手機率因此降了幾個百分點。
- 同頻加成：+X%（整隊上限 +10%）。
- 補給：這次要付多少 RVYN，從帳上還是錢包付。
- 勝算：這次實際的機率表（已套用穩定加成）。
- 這次會用掉：1 張出發令、每個 NFT 各 1 次航程。
- 一句提醒：「失敗時，補給和航程不會退回。」
- 按鈕：「出發」。

**出發後**
- 光橋動畫：從光塔射向目的地。
- 光橋在等待揭曉期間持續閃動，顯示倒數「約 X 分鐘後揭曉」。
- 揭曉時：結果字卡（空手而歸／小虧／一般／豐收／大豐收／傳說）＋倍率＋一句航行日誌（第 8 章），傳說等級有全螢幕特效。

**右側：即時探索日誌**
- 今天全體的出發次數、觀測者人數。
- 一條條動態：誰（你／錢包縮寫）、哪座光塔、去了哪個目的地、結果或「光橋上」、多久前。
- 大豐收和傳說會被標亮。
- 篩選：全部／只看我。

### 5.3 碑原：「我的隊伍怎麼組？」
- 左邊列出所有光塔；中間是選中的光塔、稜鏡座和探索者席位。
- 可以放上、拿下探索者和稜鏡；席位沒坐滿時，提示光塔和稜鏡的光度只算一部分。
- 顯示這支隊伍的總光度，以及現在能去哪些星團、目的地。
- 顯示每位探索者的光紋，方便配合每天的光。
- 停泊中的 NFT 顯示停泊倒數和「續航」按鈕。

### 5.4 光塔／探索者／稜鏡：「我有什麼？」
- 卡牌牆，可篩選稀有度、位置（錢包／在隊伍上／停泊中），可排序（稀有度、光度、剩餘航程、編號）。
- 點卡片看詳情：屬性、剩餘航程、是否續航過、出發紀錄。
- 停泊中的卡片有明顯標示和「續航」按鈕。

### 5.5 召喚：「抽卡。」
- 三種卡池，各自顯示價格、目前牌組剩餘數量和各稀有度的機率。
- 召喚是兩步驟：送出申請 → 等下一個整點的隨機種子 → 揭曉（翻卡動畫）。
- 首抽 9 折、光塔早期限購等規則照白皮書。

### 5.6 市集：「跟其他玩家交易。」
- 核心遊戲完成後再做（需要另外的合約），現在顯示「即將開放」。

### 5.7 金庫：「我賺了多少、什麼時候領？」
- 可領取的 RVYN、現在提領的手續費、等幾天後會降到多少（走勢圖）。
- 待結算的出發一鍵結算。
- 統計：總出發次數、各結果的次數、最高倍率、累計光塵、累計 RVYN、累計補給。
- 出發紀錄：依日期分組，每筆顯示目的地、結果、帶回光塵、補給。

### 5.8 圖鑑：「我收集了什麼？」
- 同頻紀錄：6 種光 × 12 個目的地。
- 結果紀錄：每個星團見過哪些結果（例如 ③ 的傳說）。
- 收藏：各稀有度、特別款、星紋。
- 星圖名冊：已歸航的探索者名字。

### 5.9 玩法：「規則是什麼？」
- 這份玩法書的玩家版：一頁看懂的流程圖、每個星團和稜鏡的勝算表、補給、同頻、續航規則、機率公開。

## 6. 每個決定和它的代價

| 決定 | 選項 | 代價與取捨 |
|---|---|---|
| 去哪個星團 | 淺／深 | 越深補給越多、空手機率越高；沒失敗時帶回越多 |
| 去哪個目的地 | A／B／C | 越後面係數越高；今天的光決定哪個同頻 |
| 用哪支隊伍 | 強隊／弱隊 | 強隊去淺處更穩（超出門檻），去深處報酬更高 |
| 用哪面稜鏡 | 廣域／聚焦／針芒 | 平均一樣，波動不同 |
| 3 張出發令怎麼分 | 集中一隊／分散 | 同一隊多次出發會更快用完航程 |
| 停泊的 NFT | 續航／讓它歸航 | 續航花原價 50%，只能一次；稀有的值得，普通的不一定 |
| 什麼時候提領 | 現在／等 | 等越久，手續費越低 |
| 組什麼光紋 | 同一種／分散 | 同一種：同頻少但強；分散：常有小加成 |

## 7. 停泊與續航流程

1. NFT 的航程歸 0：卡片變成「停泊中」，顯示 7 天倒數；如果它在隊伍上，會自動退出隊伍。
2. 玩家打開卡片：看到「續航（原價 50%）」和「讓它歸航」兩個選項，並提示「每張卡只能續航一次」。
3. 選擇續航：付款後恢復全部航程，卡片標上「已續航」。
4. 選擇歸航或 7 天到期：播放歸航動畫，名字刻上星圖名冊。

## 8. 結果與航行日誌（文案方向）

| 結果 | 意思 | 日誌語氣（範例，正式文案另寫） |
|---|---|---|
| 空手而歸 | 光橋中斷，帶不回光 | 「光橋在半途散開。探索者平安回來了，手裡什麼也沒有。」 |
| 小虧 | 帶回的比基準少 | 「光在回程時漏掉了一些。」 |
| 一般 | 接近基準 | 「一趟平穩的潛光。」 |
| 豐收 | 明顯比基準多 | 「回程的光橋比去時更亮。」 |
| 大豐收 | 好幾倍 | 「探索者回來時，整座光塔都在發光。」 |
| 傳說 | 6～10 倍（只在 ③④ 星團） | 「核光回響。整個觀測站都聽見了。」 |

每個目的地之後可以再寫專屬的日誌句子，讓同樣的結果在不同地方讀起來不一樣。

## 9. Rovyn（訊號守望者）

- 名稱：**訊號守望者・Rovyn**。
- 點一下對話框：換下一句；同一狀態有 3～5 句輪替。
- 依狀態說話（優先順序由上到下）：
  1. 沒連錢包 → 引導連接。
  2. 網路不對 → 引導切換。
  3. 新手任務沒完成 → 指出下一步。
  4. 有 NFT 停泊中 → 提醒續航或歸航。
  5. 有結果剛揭曉 → 評論結果（大豐收、傳說時特別興奮）。
  6. 還有出發令 → 推薦今天同頻最多的目的地。
  7. 有收益可以領 → 提醒手續費還有幾天降到 0。
  8. 今天都用完了 → 閒聊世界觀、預告明天的光。
- 每個星團出發前各有一句台詞（規則書第 12 章）。

## 12. 例外狀況

| 狀況 | 畫面怎麼處理 |
|---|---|
| 沒連錢包 | 可以瀏覽星圖和目的地，出發按鈕變成「連接錢包」 |
| 網路不對 | 出發按鈕變成「切換網路」 |

| 交易被拒絕或失敗 | 顯示白話的原因，可以重試 |

## 13. 合約完成前的「預覽模式」

老闆指示：先照新規則做出遊戲內容，合約之後再補。所以預覽階段這樣運作：

- **規則引擎放在前端**：星團、目的地、勝算表、補給、同頻、穩定加成、停泊與續航的數字，全部集中在一個設定檔，數字和規則書完全一致。之後寫合約時，直接照這個設定檔寫。
- **預覽模式用模擬資料**：
  - 隊伍和 NFT 先讀測試網上的真實資料；沒有的話，提供一組示範隊伍。
  - 出發、補給、結果、停泊都在瀏覽器裡模擬，存在本機，不送交易、不花代幣。
  - 結果用跟正式規則相同的機率表抽，等待時間縮短（例如 20 秒），方便試玩。
  - 畫面上清楚標示「預覽模式：結果是模擬的，不會上鏈」。
- **正式站不受影響**：預覽只放在預覽網址。正式站維持現在的測試網版本，直到 v2 合約完成並經老闆同意才切換。
- **合約完成後**：把規則引擎的資料來源從「模擬」換成「鏈上」，畫面不用重做。

## 14. 文案規則（沿用 v3／白皮書）

- 不用「挖礦、礦工、打工」等字眼；NFT 退場叫「歸航」，探索者不會死亡。
- 宣傳文案不寫期望值、報酬率、回本；遊戲內依規定公開機率和倍率區間。
- 所有合約相關說明都要註明「未經審計」。
