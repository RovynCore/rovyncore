# 潛光遠征 玩法書 v3（草案）

狀態：草案（2026-10-08），取代 v2。數值以《規則書 v3》為準；這份寫玩家怎麼玩、每個畫面做什麼。所有對白和日誌在《文本庫 v3》。
做法：先照這份把遊戲內容做出來（預覽模式，第 12 章），合約之後再補。

---

## 1. 一句話玩法

**每天 3 張出發令：挑隊伍、挑目的地、看今天的星象、在航行中做抉擇，把光帶回來。**

長期目標：
1. **往深處推進**：抽卡、交易、續航，讓隊伍戰力從 51 一路推到 1200，解鎖 24 個目的地。
2. **把握每一天**：每天的光、星象事件都不同，3 張出發令怎麼分配，每天都要重新判斷。
3. **經營卡組**：哪些卡值得續航、哪些該賣、哪些該換。

（不做圖鑑、成就、稱號、任務獎勵、小遊戲。）

## 4. 每天的一輪

1. **觀測站**：看公告、今天的星象事件、星團預報（哪裡同頻、哪裡有星潮）、剩幾張出發令。
2. **潛光**：星圖 → 星團 → 目的地 → 出發確認 → 出發。最多 3 次。
3. **等待中**：事件卡跳出來就做抉擇；右側即時日誌看大家的動態。
4. **揭曉**：結果、倍率、這趟耗損幾次航程、航行日誌。
5. **隔天**：金庫收到收益（已扣出發成本）；決定要不要提領（越晚手續費越低）。
6. **不定期**：抽卡、組隊、處理停泊的 NFT、在市集買賣。

## 5. 各頁面（一頁只回答一個問題）

### 5.1 觀測站：「今天有什麼事？」
- **今日的光**（主視覺，融入今日意象）：今天的日期、6 個星團各自的光帶，標出有星象事件的目的地。
- **Rovyn**：點一下換一句話，依狀態輪替（第 8 章）。
- **公告與活動**：後台管理，可上架、下架，有文字和連結。
- **今日次數**：出發令剩幾張、換日倒數、停泊中的 NFT 數。
- **新手任務**：第 3 章，完成後收起。
- **星團預報**（04）：今天每個星團最值得注意的目的地，包括同頻最多、有星潮、有光潮、有雷暴的地方；點一下跳到潛光頁，並帶入最適合的隊伍。

### 5.2 潛光：「今天要去哪裡？」（主要玩法）

**主畫面三層**
1. **星圖**：6 個星團由外往內排列，越內圈越靠近核心。
   - 滑鼠移上去：星團發亮、緩慢旋轉，顯示名字、戰力區間、風險等級（穩／中／險／極險／深淵／核心）。
   - 到不了的星團顯示鎖頭和「需要戰力 X」；有星象事件的星團閃一個小標記。
   - 點一下：鏡頭推進，展開星團。
2. **星團內**：4 個目的地 A–D，顯示今天的光、星象事件標記、你最強隊伍和門檻的差距。左上角「← 星圖」返回。
3. **目的地卡**（右側滑出）：名字、故事、門檻、今天的光、星象、收益係數、出發成本、耗損機率、依你選的隊伍即時換算的勝算表。

**出發確認**（一眼看懂）
- 隊伍：光塔、稜鏡（光束）、探索者；同頻的探索者光紋亮起，標示「同頻 +X%」。
- 戰力 ／ 門檻：超出多少，空手機率因此降了幾個百分點。
- 今天的星象：效果說明。
- 勝算：這次實際的機率表（已套用星象和穩定加成）。
- 出發成本：「收益回來後扣 X%」。
- 耗損：「至少 1 次航程，深處有 Y% 機率耗損 2、Z% 機率耗損 3」。
- 會用掉：1 張出發令。
- 按鈕：「出發」。

**出發後**
- 光橋動畫從光塔射向目的地，旁邊顯示「約 X 分鐘後揭曉」。
- **航行抉擇**：可能跳出事件卡，提供 2～4 個選項（求穩、求險、繞道、順其自然），寫成故事的樣子。揭曉前都可以選，沒選就當順其自然。
- **揭曉**：結果字卡＋倍率＋耗損幾次航程（耗損 2～3 時附上原因）＋一句航行日誌。大豐收和傳說有特效，傳說會在全體的即時日誌裡被標亮。

**右側：即時探索日誌**
- 今天全體出發次數、觀測者人數、今天最高倍率。
- 一條條動態：誰、哪座光塔、哪個目的地、做了什麼抉擇、結果、多久前；篩選「全部／只看我」。

### 5.3 碑原：「隊伍怎麼組？」
- 選光塔 → 放稜鏡 → 放探索者；即時顯示戰力、能去的星團和目的地。
- 顯示每位探索者的光紋，以及「今天和哪些目的地同頻」。
- 停泊中的 NFT 顯示倒數和「續航」按鈕。

### 5.4 光塔／探索者／稜鏡：「我有什麼？」
- 卡牌牆：可篩選稀有度和位置（錢包、隊伍上、停泊中、市集上架中），可排序（稀有度、戰力、剩餘航程、編號）。
- 卡片詳情：屬性、剩餘航程、是否續航過、近期出發紀錄；可以續航、上架市集。

### 5.5 召喚：「抽卡。」
- 三種卡池：今天的價格（自動換算，並顯示最低價）、牌組剩餘數量、各稀有度機率。
- 兩步驟：送出申請 → 下一個整點揭曉（翻卡動畫）。

### 5.6 市集：「跟其他玩家買賣。」
- 用 RVYN 上架、購買光塔、稜鏡、探索者；成交收 5% 交易稅（95% 回池、5% 銷毀）。
- 篩選：種類、稀有度、戰力、剩餘航程、是否續航過、光紋。
- 預覽階段先做畫面；交易功能等合約。

### 5.7 金庫：「賺了多少、什麼時候領？」
- 可領取 RVYN、現在提領的手續費、等幾天後降到多少（走勢圖）。
- 一鍵結算待結算的出發。
- 統計：出發次數、各結果次數、最高倍率、累計光塵、累計 RVYN、累計出發成本、累計耗損。
- 出發紀錄：依日期分組，每筆顯示目的地、星象、抉擇、結果、耗損、收益、出發成本。

### 5.8 玩法：「規則是什麼？」
- 玩家版的一頁說明：流程圖、戰力、24 個目的地、18 張勝算表、星象、抉擇、同頻、出發成本、耗損、停泊與續航、稅、機率公開。

## 6. 每個決定和代價

| 決定 | 取捨 |
|---|---|
| 去哪個星團／目的地 | 越深：沒失敗時帶回越多，但空手、多耗損的機率越高，出發成本也越高 |
| 要不要去今天的星象地點 | 星潮省航程、光潮多分一點但會擠、雷暴適合搏、靜海適合穩 |
| 航行抉擇 | 求穩／求險改變波動；繞道保住航程但多付 2% |
| 用哪支隊伍 | 強隊去淺處更穩（超出門檻），去深處報酬更高 |
| 用哪面稜鏡 | 平均一樣，波動不同 |
| 3 張出發令怎麼分 | 集中一隊會更快用完航程 |
| 停泊的 NFT | 續航（原價 50%，只能一次）或讓它歸航 |
| 賣或留 | 高稀有、剩餘航程多的卡在市集比較值錢 |
| 什麼時候提領 | 越晚手續費越低 |
| 光紋怎麼配 | 同一種光：同頻少但強；分散：常有小加成 |

## 7. 停泊與續航流程

1. 航程歸 0 → 卡片變成「停泊中」並顯示 7 天倒數；如果在隊伍上會自動退出。
2. 打開卡片 → 選「續航（原價 50%，只能一次）」或「讓它歸航」。
3. 續航 → 恢復全部航程，卡片標上「已續航」。
4. 歸航或 7 天到期 → 歸航動畫，名字刻上星圖名冊（在金庫或卡牌頁查看，不另設圖鑑）。

## 8. Rovyn（訊號守望者）

- 點一下換下一句；每種狀態有 6～15 句輪替。
- 狀態優先順序：沒連錢包 → 網路不對 → 新手任務 → 有 NFT 停泊 → 有事件卡待選 → 剛揭曉（依結果）→ 還有出發令（推薦今天的地點）→ 有收益可領 → 今天用完（閒聊、世界觀、明天預告）。
- 每個星團有出發台詞，每種星象有播報台詞。
- 完整台詞在《文本庫 v3》。

## 9. 公告與活動（後台）

- 表格式管理：新增、編輯、上架／下架、刪除。
- 每則：類型（消息／活動／更新／維護）、標題、內文、連結（https）、置頂、開始和結束時間、英文版（選填）。
- 前台只顯示已上架且在時間內的公告。

## 10. 例外狀況

| 狀況 | 處理 |
|---|---|
| 沒連錢包 | 可以看星圖和目的地；出發鍵變成「連接錢包」 |
| 網路不對 | 出發鍵變成「切換網路」 |
| 戰力不夠 | 目的地卡顯示「還差 X 戰力」 |
| 出發令用完 | 顯示換日倒數 |
| 隊伍裡有 NFT 停泊 | 自動退出；沒有探索者的隊伍不能出發 |
| 事件卡沒選 | 揭曉時當作「順其自然」 |
| 隨機種子延遲 | 維持等待；超過 48 小時以 1.0 倍結算、耗損 1 |
| 交易失敗 | 顯示白話原因，可重試 |

## 11. 文案規則

- 不用「挖礦、礦工、打工」；NFT 退場叫「歸航」，探索者不會死亡。
- 宣傳文案不寫期望值、報酬率、回本；遊戲內公開機率和倍率區間。
- 合約相關說明註明「未經審計」。

---

## 12. 預覽模式（合約完成前）

- **規則引擎**：所有數字集中在一個設定檔，和規則書 v3 完全一致；之後寫合約直接照它。
- **模擬資料**：讀測試網上的 NFT，沒有就給示範隊伍；出發、抉擇、星象、結果、耗損、停泊、收益都在瀏覽器裡模擬，存在本機，不送交易。揭曉時間縮短（約 20 秒），方便試玩。
- **標示清楚**：畫面標註「預覽模式：結果是模擬的，不會上鏈」。
- **只在預覽網址**：正式站維持目前版本，合約完成並經老闆同意才切換。
