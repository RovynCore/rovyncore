## 一、星團與目的地

### ① 微光淺域　The Glimmer Shallows（戰力 51～91）
離觀測站最近的一片淺空。第一道光碎裂時，最小、最溫和的碎片落在這裡；每一位探索者的第一次潛光，都從這片淺域開始。

- **A 燈籠礁**（51）：漂浮的光塵結成一圈圈淡淡的礁石，像有人在深空裡掛了燈。光橋在這裡很少斷，是練習的好地方。
- **B 迴聲灘**（60）：這裡的光會把聲音送回來。老探索者說，在灘上喊自己的名字，回來的聲音會比去的時候更亮一點。
- **C 漂光淺灣**（70）：一道緩慢的光流繞著淺灣打轉，把散落的光塵慢慢推向岸邊。等得住的人，總能撿到一些。
- **D 初明井**（80）：一口往下開的光井，井底是淺域最濃的一團光。再往下，就離開淺域了。

### ② 迴光礁海　The Echolight Reefs（戰力 92～159）
淺域之外，一片由舊光堆成的礁海。光在礁石之間反覆反射，走得越遠，迴光越亂；觀測站在這裡立了第一批導航燈。

- **A 拾光碼頭**（92）：觀測站最早搭起的前哨。光橋在這裡靠岸、補給、再出發，碼頭的燈從來沒有熄過。
- **B 雙月礁**（106）：兩顆小小的冷光衛星繞著礁石轉。兩顆月亮重疊的時候，礁縫裡的光會一次亮起來。
- **C 星砂迴廊**（122）：一條鋪滿星砂的長廊。腳步越輕，揚起的光越多；太急的人，只會把自己埋進沙裡。
- **D 潮信燈塔**（140）：礁海盡頭一座無人的燈塔，按照沒人知道的節奏閃爍。有人說，它是在回應更深處的某個訊號。

### ③ 碑影星團　The Stele Shadows（戰力 160～289）
一群巨大的碑狀星體排成長列，彼此投下影子。觀測站相信，這些碑是第一道光碎裂時留下的記號；碑原這個名字，也是從這裡來的。

- **A 長碑迴廊**（160）：沿著碑列延伸的長廊。光在碑面之間來回折射，路線清楚，但影子偶爾會吞掉一兩道光橋。
- **B 斷銘丘**（185）：一座碑斷成好幾截，斷面刻著沒有人讀得懂的紋路。探索者會在這裡撿到帶著刻痕的光塵。
- **C 影潮灣**（215）：碑影像潮水一樣漲落。漲潮時光橋最難穩住；退潮時，灣底的光會一次全部露出來。
- **D 無名碑頂**（250）：最高的一座碑，碑面是空白的。站在碑頂往下看，整片碑影星團像一張還沒寫完的星圖。

### ④ 霧光深谷　The Mistlight Gorge（戰力 290～499）
碑影後方是一道深谷，谷裡填滿了會發光的霧。霧會吞掉方向感，也會藏住光；觀測站的紀錄在這裡開始變得斷斷續續。

- **A 霧門**（290）：兩道霧牆之間的窄口，是進入深谷唯一穩定的路。穿過霧門以後，回頭就看不見碑影了。
- **B 低語谷**（335）：霧裡一直有細小的聲音，聽不清楚在說什麼。探索者說，跟著聲音走，常常會找到光。
- **C 沉光湖**（385）：一座由沉下來的光聚成的湖，湖面平得像鏡子。光橋接觸湖面的那一刻，最容易斷，也最容易滿載。
- **D 霧心**（440）：深谷的中心，霧在這裡濃到幾乎是固體。很少有光橋能撐到這裡，但撐到的都帶回了不一樣的東西。

### ⑤ 裂光星團　The Riftlight Expanse（戰力 500～839）
空間在這裡裂開，光從裂縫噴出來，又被裂縫吞回去。觀測站把這裡標成「殘酷」：光很多，但光橋常常撐不到回程。

- **A 碎鏡原**（500）：一大片碎裂的光面，每一片都映出不同方向的路。踩錯一片，光橋就斷在半空。
- **B 雷鳴峽**（570）：裂縫之間不停打著光的雷。探索者得在兩次雷鳴之間穿過去；時機對了，帶回來的光多到裝不下。
- **C 逆流裂口**（650）：這道裂口的光是往回流的，光橋得逆著光走。走得越久，越分不清自己是在前進還是後退。
- **D 無返隙**（740）：名字來自觀測站最早的一份紀錄。那次光橋斷了三次才接回來，最後一段訊號只有一句話：「這裡的光，會回頭看你。」

### ⑥ 核心星冠　The Core Crown（戰力 840～1200）
環繞 ROVYN CORE 的最後幾圈光環，也是星圖上最亮、最危險的地方。這裡的光，最接近第一道光本身。

- **A 冠環外緣**（840）：光環的最外圈，已經感覺得到核心的熱。多數探索者是在這裡，第一次看見核光真正的顏色。
- **B 七重日冕**（950）：七層光冕一層壓著一層。每穿過一層，光橋就要重新校準一次。
- **C 核光之階**（1070）：一道往核心延伸的光之階梯，每一階都比上一階更亮。沒有人知道它有幾階。
- **D 第一道光**（1180）：星圖的盡頭。沒有人真正抵達過核心，只有最強的隊伍能靠近到看見它的輪廓，再把那一點光帶回家。
