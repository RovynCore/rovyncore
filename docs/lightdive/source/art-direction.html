00 怎麼使用這份文件

這份文件是 docs/lightdive/ART-ASSETS.md 第 4、5 節（Signal-Keeper、介面素材）的詳細版。NFT 圖（探索者、光塔、稜鏡）仍以 ART-ASSETS.md 第 1–3 節為準。

每一項素材都用同一個結構寫：

一個原則：分工

你負責「只有畫得出來才有的東西」：氛圍、材質、角色、場景。程式負責「會動、會變、會跟數字連動的東西」：介面框線、數字、光橋、粒子、閃爍、稀有度光效、按鈕。所以這份文件常常會要求「這裡留空」「這裡不要畫光暈」「這部分拆成獨立圖層」。這些要求的目的，是讓同一張圖在遊戲裡能活起來。

02美術總綱：世界、光、色彩、材質

2.1 這個世界的一句話

在一片幾乎全黑的深空裡，光是唯一有價值的東西。

星系中心的 ROVYN CORE 發出第一道光（核光 RVYN），碎成千萬片沉進深空。觀測者在核心周圍建起光源觀測站、立起光塔，用共鳴稜鏡把晶核的光折成光橋，讓探索者順著光橋潛進深空，把光帶回來。這就是「潛光」。

「潛進深空，把第一道光帶回來。」Dive deep. Bring the First Light home.

所有美術判斷都可以回到這句話：黑暗是預設值，光是獎勵。畫面越暗、光越少，光出現時就越珍貴。這也正好對應遊戲的核心循環：玩家每天把探索者送進黑暗，等待他們帶光回來。

2.2 視覺關鍵字

深空寂靜
大面積的黑與深炭灰，留白多。不是熱鬧的太空歌劇，而是安靜、遙遠、有點孤獨的觀測。
古老與精密並存
光塔是分體古石巨碑；守夜人的面具有裂紋；但晶核、終端、軌道是精密的。像一座運轉了很久的天文台。
光是訊號
光不是爆炸、不是火焰。它是穩定、細、銳利的線與點：軌道、瞄準環、光橋、刻度。

2.3 光的語言

這個遊戲裡，光的顏色和形狀都有意義。請在所有素材裡遵守，玩家會在不知不覺中學會這套語言。

光意義用在哪裡
核光萊姆核光 RVYN 本身：價值、收穫、系統的「生命」。胸口核心、眼睛、光橋、軌道、成功結果。它是全遊戲唯一的品牌光色，其他光色都只能當配角。
白熱強度的極限：核光濃到發白。只用在核光萊姆的最亮中心點，以及「核光回響」等最高等級的結果。
六種屬性色光源的種類（曦光、霧光、晶光、熾光、雷光、淵光）。只出現在屬性圖示、座標標記、探索者光紋。不可以用在場景主光，否則會和核光萊姆搶。
熄滅訊號中斷、航程結束。光橋中斷、立繪「低頭」姿勢、已歸航的探索者。不是血紅、不是警報，只是光暗下去。

3.3 畫面比例與安全區

Lightdive 是網頁遊戲，同一張背景要在桌機橫螢幕（16:9 到 21:9）和手機直螢幕（9:16 到 9:19.5）都好看。背景類素材（A1、A2）的做法是：

  • 主要內容放在「安全區」：任何比例裁切都看得到的範圍。各項的安全區畫在該章的示意圖裡。
  • 安全區外要「可以被裁掉」：放延伸的天空、結構、霧氣，不放關鍵物件。
  • 介面區域要夠暗：介面文字會壓在背景上。標示為介面區的地方，平均亮度要低於 10%（HSL 的 L 值），並且不能有高對比的細節，否則文字讀不清楚。

3.4 透明素材的做法

  1. 生圖時用純中性灰底（#808080）或純黑底，不要用場景背景。
  2. 去背後，用「去除邊緣色」（Photoshop：圖層 → 修邊 → 移除黑色／白色邊緣）處理邊緣。
  3. 發光部分（萊姆光）不要和本體一起去背：放到獨立的發光層，用黑底交付即可，程式會用「相加」模式疊上去。詳見 A4。
  4. 交付前，把成品放在三種底色上檢查：#0B0C0E（遊戲底色）、#808080、#FFFFFF。三種底色都不能看到灰邊或殘影。

3.5 關於生圖工具

哪些項目適合生圖，哪些不適合

適合：A1 星圖背景、A2 觀測站場景、A3 立繪、A7 卡背底圖。生圖之後通常還需要修圖、補細節、統一色調和拆層，請預留時間。

不適合：A5、A6 圖示和 A8 字標。生圖工具做不出精準、可縮放、筆畫一致的向量圖示和文字，這幾項請由設計師用向量工具繪製（Figma、Illustrator、Inkscape 皆可）。生圖可以拿來找靈感。

敘事

核光碎片沉進了星系深處。觀測者用星圖記錄每一個光源的位置與深度：離核心越近越淺、越亮、越安全；越往外越深、越暗，但那裡的光源更罕見。星圖的中心就是光源觀測站和它背後的 ROVYN CORE。

星圖也是發射台的延伸：白皮書第 4.3 節寫到「每一次在發射台上的發行，星圖上就會多出一個光點」。所以這張圖要讓人感覺還有很多空位會被點亮，是一個會成長的宇宙。

為什麼要拆

Signal-Keeper 沒有臉，他的「表情」全部來自光：核心的亮度、眼睛的閃動、軌道球的運轉。如果光被畫死在圖裡，立繪就只能是一張靜止的圖。拆成獨立圖層後，程式可以：

  • 讓核心規律地呼吸（平靜時慢、緊張時快）
  • 讓眼睛偶爾閃一下，像在眨眼或接收訊號
  • 讓軌道球沿著軌道緩慢運轉，並正確地從身體後方繞到前方
  • 在揭曉時把光推到最亮，在光橋中斷時讓光閃爍熄滅

這是遊戲裡最有效的「精緻感」來源，成本卻只是多拆幾個圖層。

發光層的畫法

  • 顏色：核心外圈與刻度用核光萊姆 #C9FF55；核心正中心可以接近白色 #F4F6EE。眼睛同理。

  • 軌道環的線寬約 3–4 px（在 1024 寬的畫布上），萊姆色，線本身清楚，不畫光暈。

A8 · LOGO_LIGHTDIVE
標題字標
「Lightdive 潛光遠征」的正式字標。

敘事

Lightdive 的意思就是遊戲的核心動作：潛進黑暗，把光帶回來。字標要在一眼之內傳達「光」與「下潛」兩個意象，並和 RovynCore 品牌（萊姆光、深色、精密）同一家族，但有自己的個性。

使用場景

場景尺寸底色
遊戲首頁、載入畫面寬 600–900 px深色場景
分享圖、社群貼文寬 400–700 px深色
網站導覽列、頁尾高 20–28 px深色或淺色
白皮書、文件封面不定白色

內容與版本

  • 主字標：英文「LIGHTDIVE」。它是全球共通的名稱，不翻譯。
  • 副標：在地化名稱，獨立成可替換的圖層，因為遊戲有四種語言：
    • 繁體中文：潛光遠征
    • 簡體中文：潜光远征
    • 韓文：待文案組確認（白皮書第 14.2 節第 7 項，需母語者確認）
    • 英文：Expedition（或不加副標，由文案組決定）
  • 兩種排版：橫式（主字標與副標左右或上下並排，寬高比約 4:1）、直式堆疊（約 1.6:1）。

造型方向

  • 字體：幾何、偏窄、科技感的無襯線字，大寫。可以用商用授權字型改造，或完全自繪。字型授權必須允許商標用途，並在 log 裡記錄字型名稱與授權。
  • 下潛的意象：建議在一個字母上做一個細節，例如「I」的點變成一顆萊姆光點，或「V」的底部延伸出一道向下的細光線，像光橋往深處延伸。只做一處，不要每個字母都加裝飾。
  • 顏色：主字標用骨白 #D8D6CE 或純白，只有那一處光點或光線用核光萊姆。
  • 和副標的關係：中文副標的字重比英文輕一級，字距加大，放在主字標下方或右側。

  • 與 RovynCore 網站現有的字標放在一起不衝突。

13驗收流程與生成紀錄

13.1 驗收流程

  1. 自我檢查：交付前用該項的驗收清單逐項打勾。
  2. 交付：依第 3.2 節的資料夾結構，連同 log 一起交付。
  3. 實機放入：開發端在 1–2 天內把素材放進測試網版本，產出桌機（1920×1080）、手機（390×844）的實機截圖或錄影。
  4. 回饋：開發端依同一份驗收清單回報，並附上截圖標註問題位置。只有在「技術上無法使用」時才要求重做（例如分層不對齊、安全區被佔用）；風格判斷以美術負責人的決定為準。
  5. 定版：素材定版後放進 repo（public/ 下的遊戲素材目錄），母檔另外保存。
