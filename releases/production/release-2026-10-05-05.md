- `PresaleConsole` (home and `/rvyn`, four languages): a HUD-style four-stage track (Prep, Whitelist, Presale, Closed) highlighting the live stage, a progress gauge, live readouts for whitelist registration, presale purchases and wallets listed, and a countdown that appears only when a registration window is scheduled or open. It reads the existing public `rvyn/status` endpoint every 30 seconds and never invents dates or numbers: missing data shows "TBA", a failed read shows everything closed. A second panel shows the V5 contract allocation caps (10,000,000 RVYN) as an interactive donut, labelled as contract caps and not as tokens sold or distributed. Reduced-motion is respected; no horizontal overflow at 390 px.
- Admin "Multisig proposals (Safe)" panel (below the sale desk): for a Safe-sponsored sale it prepares the on-chain steps (publish whitelist root, approve and deposit inventory, open, close) as a downloadable Safe Transaction Builder batch with calldata and a link to the Builder. It never sends a transaction. Existing admin buttons are unchanged.

Read-only preflight checks Safe owners and the 2-of-3 threshold, RVYN supply, router factory/WETH and simulated gas. Simulation against mainnet passed; the new runtime differs from the verified V5 only in address-sized immutable ranges. Nothing was deployed or signed.
