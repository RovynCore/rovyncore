Admin dashboard rework, X auto-sync removal, and the switch to the multisig-sponsored V5.

- Admin dashboard: the single long page is split into five tabs (Overview, Presale, Platform and fees, Content and reports, Site settings) using a `data-admin-tab` tag on each existing section, so no action or handler changed. They are now shown for V5, and the `replace` flag is sent whenever a sale is already registered; the Worker still only allows replacement when the old sale was never opened, funded or stocked.
