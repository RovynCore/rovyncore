# Production release 2026-10-05-13

Recorded 2026-10-05 (UTC+8). Worker d6e8460f-b547-482b-bb7c-935fa46f069c. Released by Claude Code under the founder's direct-production authorization for website updates.

First-impression pass and the layout pass for Launchpad, Onchain Records and the footer. The founder's reference was getlayers.ai: a site that feels premium the moment it opens.

- Boot intro (home page, first visit of a browser session only): a short full-screen sequence (a drawing ring, a letter-by-letter wordmark, a three-line fact log, a progress bar) that splits open to reveal the hero. Any key press or click skips it; a six-second failsafe in the root layout removes it if scripts fail; it is skipped for reduced-motion users and for later visits in the same session. The facts it prints are fixed ones (network 4663, 10,000,000 supply, first game in development).
- Hero: now a rounded, framed stage with a floating glass navigation pill above it; the headline is larger and the copy, buttons and telemetry rail rise in with a staggered blur-in after the intro; the crystal and the HUD layers drift against each other with the pointer (desktop pointers only).
- Smooth scrolling: inertial wheel scrolling through the new `lenis` dependency (1.3.26, `package.json` and lock updated), enabled only for desktop pointers without reduced-motion; touch and keyboard behavior is native. The wallet dialog opts out so its own scrolling works.
- Scroll-linked entrances for sector markers, headings and cards via CSS `animation-timeline: view()` where the browser supports it; other browsers simply show the content.
- Launchpad: step track with a lime active chip, mono field labels, a sticky preview and summary column, larger fee readout. Onchain Records: a four-fact rail under the title (network, source, order, immutable origin snapshot), a framed toolbar, numbered record cards. Footer: a `SEC·END` ruler with a back-to-top button, mono column headings, an outlined wordmark with a slow light sweep. The `/rvyn` hero uses the same framed stage.

Eleven changed source files against 2026-10-05-12 (manifest 287 files): app/console-theme.css, app/home-redesign/page.tsx, app/layout.tsx, app/onchain-record/page.tsx, components/hero-hud.tsx, components/hero-parallax.tsx (new), components/intro-splash.tsx (new), components/platform-provider.tsx, components/smooth-scroll.tsx (new), package-lock.json, package.json.
