Recorded 2026-10-05 (UTC+8). Worker a217091a-754d-450e-a038-c162d2423060 (an earlier publish of the same policy without the analytics hosts was Worker 6706f947). Released by Claude Code under the founder's direct-production authorization for website updates.

Engineering follow-up from the external review "RovynCore Presale V6 and Ops Improvements" (founder-provided PDF, 2026-10-05).

- Content-Security-Policy in report-only mode (`scripts/production-worker.mjs`): `default-src 'self'`, inline scripts and styles allowed for now, images from any https origin, `connect-src` limited to the site, the two Robinhood Chain RPC hosts and Cloudflare Web Analytics, `frame-ancestors 'self'`, `object-src 'none'`. - Public source export: the earlier export left out four things the build needs (`build/` vendored plugin, `.openai/hosting.json` bindings, `vendor/` stylesheet and the CI workflow). They are now included, `.github/workflows/ci.yml` runs typecheck, lint, unit, contract, build and API tests, and a fresh clone on another drive now installs, typechecks, lints, builds and passes the unit (12), contract (22), presale V5 (5) and API (30) tests.
