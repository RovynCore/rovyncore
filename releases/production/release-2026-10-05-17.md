# Production release 2026-10-05-17

Recorded 2026-10-05 (UTC+8). Worker 1d45ab4e-0486-4990-b227-9ffc74340344. Released by Claude Code under the founder's direct-production authorization for website updates.

Website groundwork for the RVYN presale V6 candidate (`docs/PRESALE-V6.md`). V6 is **not deployed on chain** and the site still points at the V5 sale `0x6496…46ac`; this release changes nothing a visitor sees.

- Code that recognises V6 (`presaleVersion` 6): the sale-registration check (bytecode, constructor parameters, sponsor/team/LP wallets must be the admin wallet or the Safe, 50% floor and 7-day grace constants), the admin dashboard status reads (settle window, minimum and maximum pool, operating funds, claimable remainder), the admin page (settle button replaces the V5 pool buttons), the public `/rvyn` purchase and claim flow (claim after settlement, no refund), and the overview card. The repeated V4/V5 version checks in the API route were folded into two helpers.
- Safe proposal panel (admin): new steps for settle (pool ETH between the shown minimum and maximum), withdraw unlocked operating funds and cancel before opening. Cancel also works on the current V5 sale, which is how its unused inventory would be returned.
- Registration of a replacement sale now also accepts a cancelled old sale (state 4) with no raise and no inventory.
- V6 artifacts (`packages/contracts/v6/artifacts`) added; they are compiled output of the unaudited candidate and are not used on chain.
- Four-language strings for the new admin text.

Deliberately not changed: public legal text, `/rvyn` terms copy and `/transparency` still describe V5 (instant delivery, pool up to 50%). They must be switched to V6 wording in the same release that registers a V6 sale. The RVYN health panel still reads V5 getter names.
