# Production release 2026-10-05-25

Recorded 2026-10-06 (UTC+8). Worker b3cc2dc9-f54c-4cf2-a1e4-28ade069c677. Released by Claude Code under the founder's direct-production authorization for website updates. The founder reviewed the redesign preview and said to deploy it once the X post block was removed.

Site-wide redesign. Every function is unchanged.

- New single design system: `app/rv.css`, plus shared components in `components/rv/` (header, footer, address chip, countdown, sale status, allocation bar).
  - The overlay stylesheets, marquee and serif type are gone from public pages.
  - The admin pages keep their previous look through `app/admin/legacy.css`.
- Navigation now leads with the brand's main products: Game and RVYN. Launchpad and Onchain Records sit under Tools, followed by Transparency and Updates.
- The intro splash plays only on a first visit (`localStorage` `rv-intro`).
- Rebuilt pages: home, RVYN, game, launchpad, Onchain Records, asset record, transparency, updates and terms.
  - All wallet, registration, purchase, claim, refund, launch, edit and report logic is kept as before.
  - The terms page gained a plain-language "In short" summary.
- Updates (`/latest-info`) now shows only the development log, by the founder's decision.
  - The saved X post feed is no longer rendered and the page no longer reads it.
  - The `x-updates` API and admin tools are unchanged.
  - The 2026-10-06 log entry has a line describing the redesign (version 2026.10.06-02).
- `tests/api-integration.mjs` changes:
  - Asserts that the updates page shows the log and not the X posts.
  - Skips the signed X import check when X's public oEmbed service is unreachable. `publish.x.com/oembed` returned 404 on 2026-10-06.

No contract, API route, database or configuration change. No D1 migrations and no onchain transactions.
