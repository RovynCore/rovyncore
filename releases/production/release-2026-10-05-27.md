## Lightdive testnet game on the site

This release adds the Lightdive testnet game from PR RovynCore/rovyncore#1 (branch `claude/kind-wright-ogk2hq`, built in a separate Claude session). The branch was merged locally into the public repository's main as commit c1ed823 and copied into this source folder.

New routes:
- `/game/lightdive`: mint, my spires, collection, voyage log and public odds, in four languages.
  - The page is `noindex, nofollow` and is not linked from the menu.
  - It reads and signs on Robinhood Chain testnet (46630), using test RVYN only.
- `/admin/lightdive`: pool accounting, randomness status, decks and caps, sale start and pause, parameters, and accepting ownership.

Merged code:
- `components/lightdive/*`, `lib/lightdive.ts`, `lib/lightdive-copy.ts`
- `packages/web3/lightdive.json`, which holds the testnet addresses from deployment block 130017649.
- `packages/web3/lightdive-abi.json`
- `PlatformContext` gains `walletProvider` and `switchWalletChain`.
- Contracts in `packages/contracts/lightdive/` (unaudited candidates), with `tests/lightdive.test.mjs`.
- Scripts: `lightdive-deploy` (refuses mainnet) and `lightdive-operator`.
- `docs/lightdive/`: whitepaper v1.0, simulation, WORKLOG and art checklist.
- CI step `test:lightdive`, plus the `lightdive-operator` scheduled workflow. That workflow runs only from the GitHub default branch.

Website-side change: `components/lightdive/lightdive.css` uses the old `--c-*` console tokens, which public pages no longer load. `app/rv.css` maps them onto the current palette, scoped to `.ld`.

`package.json` conflict resolution kept both sides:
- The V6 test script with its fuzz test, and `v6:preflight`.
- The four Lightdive scripts.

No change to mainnet contracts, the RVYN sale, the API, D1 or configuration. This release sent no transactions. The testnet contracts were deployed earlier by the other session; see `docs/lightdive/WORKLOG.md`.
