## 1. GitHub main: PR RovynCore/rovyncore#2 (merge commit b8c3777)

The 13 commits were built in a separate Claude session. They change the Lightdive **testnet** version:
- Randomness moves from hourly to one-minute slots (`RandomnessBeacon` daily hash chains, `currentSlot`). A mint uses the current slot. A dive resolves from the slot five minutes after departure (`Expedition.DIVE_SLOTS`).
- Spire and prism special editions are removed from the contracts, the ABI and the copy.
- `packages/web3/lightdive.json` points to the redeployed testnet contracts.
- New `workers/lightdive-operator` and the GitHub workflow `lightdive-operator-deploy.yml`, which deploys the operator Worker. This release did not deploy the operator.
- Art direction documents in `docs/lightdive/`: art direction v1.0, NFT art direction v2.1, and Signal-Keeper reference images.

How it was merged into the source folder (base: the previous public sync a4be5e3):
- 30 files had no local change and were taken from GitHub as they are.
- `components/lightdive/lightdive-admin.tsx` merged cleanly.
- `lib/lightdive.ts` had one conflict in the `MintRequest` type. The resolution uses GitHub's `slot` field and keeps the local `DiveOutcome` and `BeamTier` types. The local event and outcome readers were renamed from `hour` to `slot` to match the new ABI.
- `components/lightdive/lightdive-game.tsx` had been replaced locally by the rebuilt testnet game in `components/lightdive/game/`. PR #2's changes were ported there instead:
  - The signal and draw timers count one-minute slots.
  - Dive buttons follow `diveScheduled`.
  - The game copy in four languages now says a draw opens in about a minute and the light answers about five minutes after departure.
  - The special-edition names and chips were removed.

## Follow-up: lockfile correction (after the deploy)

- GitHub CI failed at Install on the sync commit. The local `package-lock.json` had an expanded copy of ganache's nested dependency tree; in it, `ganache/node_modules/fsevents` (macOS only) was not marked optional, so `npm ci` stopped with EBADPLATFORM on Linux and Windows.
- The lockfile was rebuilt from the previous public lockfile with `npm install --package-lock-only`, which added only the five new packages: `@fontsource/chakra-petch`, `gsap`, `pixi.js`, `pixi-filters` and `@iconify-json/game-icons`.
  - Outside ganache's bundled tree, every resolved version is the same as in the lockfile this release was built from, so the deployed build is unaffected and was not redeployed.
  - A clean `npm ci` with the rebuilt lockfile installed 744 packages without error.
- The source inventory above records the lockfile the build used.
