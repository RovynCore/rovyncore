## 2. Website

- **/game/lightdive**
  - It is the v3 game, played on the contracts above with the player's wallet (components/lightdive/v3/use-chain.ts, live.tsx, live-ui.tsx; reads in lib/lightdive-v3/onchain.ts).
  - Search engines may index it now. The v2 testnet game UI it replaces is no longer routed.
- **How the game works on chain:**
  - Results: a dive's result is computed in the browser from its drand round exactly as Expedition3 settles it. Collecting sends the reveal.
  - Summons: a summon is paid, then opened with its drand round.
  - Teams: team changes are drafts until saved, one transaction per team.
  - Testnet faucet: "Buy $RVYN" is replaced by a test-token page with the claim button and links to Robinhood's gas faucets.
  - Badges: the testnet is marked everywhere as "test tokens, no value, contracts not audited".
- **/game/lightdive/preview** is still the simulated preview, now explicitly `noindex`.
- **/game** now says the testnet is open and has a "Play" button. The milestone marker is on "Playtest", and the mainnet launch has no date. The site menu badge for Game reads "Testnet" instead of "Soon".
- **/transparency** section 02 reads the live counts from the deployment the game uses: alive, on teams, listed and idle per kind. It is labelled as testnet figures.
- **Translations:** 80 new strings in four languages (lib/lightdive-v3/i18n/live.ts).
- **Other changes in this release:**
  - Summon quantities follow the contract (spires 1/3, prisms 1/5, seekers 1/5/10).
  - Rovyn no longer names a destination when no team can reach one.
  - GitHub PR #3 (operator CPU fix, testnet v2 operator) is merged into the source.

**No D1 migration.** No onchain action by Claude. The testnet deploy was done by the founder. Vars were kept (`--keep-vars`).
