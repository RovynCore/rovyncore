# Production release 2026-10-05-32

Recorded 2026-10-16 (UTC+8). Worker 594f16d7-5cd0-4e2e-81ee-9cca6d7b091f. The founder pointed out that the tutorial on the star map gives the player no next step: it only had "Skip tutorial" and advanced only when the player acted.

## What changed

- **Tutorial coach** (`components/lightdive/v3/starmap.tsx`): every step now has a next button.
  - Step 1: "Next: go to ① The Glimmer Shallows" opens that cluster.
  - Step 2: "Next: pick a destination" opens the deepest destination in the cluster that the strongest team can reach.
  - Steps 3 and 4: "Next" moves to the following explanation. Departing stays the player's own click, because it spends a Dive Pass and gas.
  - Step 5: "Got it, let's play" as before.
  - The guide still follows the player's own actions; "next" can move it ahead but never back.
- **Music fade fix** (`components/lightdive/v3/audio.ts`): the fade could set the volume to a tiny negative number on its first frame, which the browser rejects with an uncaught error. The fade now clamps to 0–1.
- **Translations:** 3 new strings in four languages.

**No D1 migration and no onchain action.** Vars were kept (`--keep-vars`).
