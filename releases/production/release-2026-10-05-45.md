# Production release 2026-10-05-45

Recorded 2026-10-20 (UTC+8). Worker 897f601c-e5d2-4117-9ae9-665b141e803f. This is round two of the UI pass the founder asked for, played as five kinds of player: a site visitor, a new testnet visitor without a wallet, a new preview player from zero, a returning player, and English, Korean and phone players. The full write-up is in the founder's private folder (`研究/2026-10-20-玩家視角使用心得.md`). There is no contract change and no migration.

## What changed

- **No flash of English on every page load.**
  - The language picker now also writes a `rovyncore-lang` cookie (one year, `SameSite=Lax`, `Secure`).
  - The root layout reads it with `cookies()`, so the server renders the page and `<html lang>` in the saved language.
  - Visitors and crawlers without the cookie still get English.
  - A choice saved before this release (`localStorage` only) is applied once and writes the cookie.
- **Browser tab title:** Lightdive pages now read 潛光遠征, Lightdive, 潜光远征 or 라이트다이브 instead of the home page's title. `/admin/*` pages read 管理平台.
- **Tutorial:** while a destination card is open, the tutorial card narrows so the two never overlap.
- **Top bar:**
  - The testnet / preview notice wraps inside itself, up to two lines.
  - The spacer can shrink to nothing.
  - Together these keep the day clock on the first row in English and Korean at 1366px.
- **Smaller fixes:**
  - The brand line ("LIGHTDIVE · 미리보기 v3") fits.
  - Feed times stay on one line.
- **The live game's first screen for a visitor without a wallet:**
  - It adds a 先試玩預覽版（不用錢包）button that opens the preview.
  - Rovyn welcomes a visitor instead of talking about unused passes.
  - An observer with no cards yet hears about the first summon.
- **Home page daily:** on a day with no dives it shows only Rovyn's line and the way into the game, not six zeros.
- **Naming:** Rovyn's title there now matches the game (訊號守望者 / 신호 감시자).
- **Translations:** i18n `v38.ts` (6 rows).

Vars were kept (`--keep-vars`). No D1 migration, no onchain action.
