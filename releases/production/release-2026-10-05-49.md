# Production release 2026-10-05-49

Recorded 2026-10-21 (UTC+8). Worker 923a0ab8-0087-4ff6-9ee8-8bfec51170b5.

The founder approved the database change on 10-21 ("可以"). With it, 自訂檔案 choices are now saved on the server, so anyone who opens an observer's profile sees what that observer chose.

## Database

- **Migration:** `drizzle/0004_lightdive_profile.sql` was applied to production D1 `rovyncore-prod-db` before the deploy. Migration 0004 was the only one pending.
- **New table:** `lightdive_profile`.
  - `account` (lowercase address) is the primary key.
  - `style` is cleaned JSON.
  - `updated` is a timestamp.
- **Unchanged:** no other table changed, and no data was moved.

## What changed

- **`GET /api/lightdive/profile?account=0x…`:** returns the observer's style, or `null`.
  - Rate-limited with the other public Lightdive reads.
  - Kept at the edge for 30 seconds.
  - A malformed address gets 400.
  - If the table were missing, it would answer `off`.
- **`POST /api/lightdive/profile`:** saves the signed-in wallet's own style.
  - Requires the wallet session; without one it gets 401.
  - Same-origin and rate limits apply, as for every POST.
  - The value is cleaned by `cleanStyle` (`lib/lightdive-v3/profile.ts`): only preset indexes, scene ids, stat keys and section keys are kept, and unknown fields are dropped. Nothing free-form is stored or shown to other players.
  - Saving clears the edge copy.
- **Game, live:**
  - **One's own profile:** choices save to the server about 0.7 s after the last click. A copy stays on the device for the reveal's share image.
  - **Earlier choices:** a style chosen on the device before this release is sent up once.
  - **Status line:** the editor shows the save state: saving, saved, "please reconnect and sign in", or failed.
  - **Someone else's profile:** shows their saved choices.
- **Game, preview:** unchanged. The preview still keeps the choices on the device only, and says so.
- **Translations:** i18n `v41.ts` (7 rows).

Vars were kept (`--keep-vars`). There was no onchain action.
