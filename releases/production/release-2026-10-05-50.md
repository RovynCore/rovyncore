# Production release 2026-10-05-50

Recorded 2026-10-22 (UTC+8). Worker 9f70682c-f40e-46c6-b1b8-b5291810d0c2.

This release adds two things the founder approved on 10-22:
- an address lookup on the profile;
- the first batch of the 10-21 supplement art, wired into the game.

There is no contract change, no migration and no onchain action.

## What changed

### 查看觀測者 (address lookup)
- `profile-finder.tsx` sits in the profile header's top right.
- Paste a wallet address and that observer's profile opens. One's own address returns to one's own profile.
- A malformed address is refused with a note.
- The last 5 addresses looked up are kept on the device as chips.
- The preview shows a note instead, because its other observers are simulated.
- Someone else's profile has a "複製這個地址" button.

### Supplement art (74 images, the founder's, tool: built-in image_gen)
- **Source:** the originals are in `docs/lightdive/art/incoming/misc/{dest,reveal,event,sky,titles}`. LOG.md has 74 rows. The prompts and the delivery record are under `prompts/supplement-2026-10-21.*`.
- **Conversion:** `scripts/lightdive-art-webp.mjs` gained six jobs. Re-running it left every existing WebP byte-identical.
- **Paths:** `lib/lightdive-v3/art.ts` holds the path helpers.
