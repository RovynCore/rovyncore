### Verify a dive
- **Page:** `/game/lightdive/verify/<dive id>` takes no wallet. It shows the dive as recorded, the drand signature (linked to the drand API), `sha256(signature)`, the value mixed with the dive id, and the odds table row it falls in. It also shows the multiplier and wear rolls and the reward.
- **Comparison:** the page compares the recomputation with the `Revealed` event. A dive that is not yet settled shows the result its next transaction will write.
- **Logic:** `lib/lightdive-v3/verify.ts` (`explainDive`).
- **Test:** `tests/lightdive-v3-verify.test.ts` checks every step against `drawDive` (which the smoke test checks against the chain), using real drand evmnet signatures, every odds table and several dive ids. It also checks the lamp-oil wear.
- **Links:** the live game's reveal dialog has "自己驗證這趟結果".
